3-DoF Mathematical Derivation, Lossless Convexification & Literature Validation

1. What is 3-DoF in Powered Descent Guidance?

In aerospace trajectory optimization, 3-DoF (3 Degrees of Freedom) represents the full 3D spatial translation of a point-mass vehicle:

3D State Vectors: $$ \mathbf{r}(t) = \begin{bmatrix} x(t) \\ y(t) \\ z(t) \end{bmatrix} \in \mathbb{R}^3, \quad \mathbf{v}(t) = \begin{bmatrix} v_x(t) \\ v_y(t) \\ v_z(t) \end{bmatrix} \in \mathbb{R}^3, \quad \mathbf{u}(t) = \begin{bmatrix} u_x(t) \\ u_y(t) \\ u_z(t) \end{bmatrix} \in \mathbb{R}^3 $$ where $x$ is downrange, $y$ is crossrange, and $z$ is altitude above the landing pad.

(Note: 6-DoF introduces the 3 rotational degrees of freedom: roll, pitch, yaw and angular rates $\boldsymbol{\omega}$. In modern guidance, 3-DoF guidance generates the fuel-optimal acceleration command $\mathbf{u}^*(t)$, and an inner-loop attitude controller commands engine gimbals and RCS to point the vehicle accordingly.)

2. 3D Second-Order Cone Constraints & Lossless Convexification

The minimum engine throttle constraint $0 < u_{\min} \le \|\mathbf{u}(t)\|$ creates a non-convex spherical shell. Açıkmeşe & Ploen (2007) relaxed this via the slack variable $\Gamma(t)$:

  • 3D Second-Order Cone (SOC): $$ \sqrt{u_x(t)^2 + u_y(t)^2 + u_z(t)^2} \le \Gamma(t) $$
  • Thrust Magnitude Bounds: $$ u_{\min} \le \Gamma(t) \le u_{\max} $$
  • 3D Thrust Pointing Cone (Gimbal Limit): $$ u_z(t) \ge \Gamma(t) \cos \theta_{\max} $$
  • 3D Glide-Slope Terrain Cone: $$ z(t) \ge \sqrt{x(t)^2 + y(t)^2} \tan \gamma_{\text{gs}} $$
  • Objective: $$ \min \int_0^{t_f} \Gamma(t) \, dt $$

import numpy as np import cvxpy as cp def solve_gfold_3d(r0, v0, tf=12.0, N=60, a_max=25.0, a_min_ratio=0.3, theta_max=35.0, gamma_gs=20.0): dt = tf / N a_min = a_max * a_min_ratio cos_theta = np.cos(np.radians(theta_max)) tan_gamma = np.tan(np.radians(gamma_gs)) g_vec = np.array([0.0, 0.0, -9.80665]) # 3D Decision Variables r = cp.Variable((3, N + 1)) # [x, y, z] v = cp.Variable((3, N + 1)) # [vx, vy, vz] u = cp.Variable((3, N)) # [ux, uy, uz] gamma = cp.Variable(N) # Thrust magnitude slack cost = cp.sum(gamma) * dt constraints = [ r[:, 0] == r0, v[:, 0] == v0, r[:, N] == np.zeros(3), v[:, N] == np.zeros(3) ] for k in range(N): a_net = u[:, k] + g_vec constraints += [ r[:, k+1] == r[:, k] + v[:, k]*dt + 0.5*a_net*(dt**2), v[:, k+1] == v[:, k] + a_net*dt, # 3D Second-Order Cone: ||u||_2 <= gamma cp.norm(u[:, k], 2) <= gamma[k], gamma[k] >= a_min, gamma[k] <= a_max, # 3D Gimbal cone: uz >= gamma * cos(theta_max) u[2, k] >= gamma[k] * cos_theta, # 3D Glide-slope cone: z >= ||[x, y]|| * tan(gamma_gs) r[2, k] >= cp.norm(r[0:2, k], 2) * tan_gamma, r[2, k] >= 0.0 ] prob = cp.Problem(cp.Minimize(cost), constraints) prob.solve(solver=cp.CLARABEL) return r.value, v.value, u.value, gamma.value
